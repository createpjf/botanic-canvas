退出码：`0` 仅表示离线质量门槛通过，**不是发布许可**；`1` 表示质量阻断；`2` 表示证据缺失、不完整、格式错误或来源发生变化，不能按部分结果放行。源码改变后旧证据仍可作历史记录，不能冒充新实现已验证；不要为了通过门禁手改原始哈希。哈希是本地一致性检查，不是提供商响应真实性证明。

此门禁只用于 O5 功能启用前的独立评估，不加入通用 `release:ready`，避免尚未接入的分类器阻断与它无关的产品修复发布。通用发布门禁仍需独立满足。

## 3. 发布阶段与回退

用户已选择旁路，新增 `server/agent/tools/agentToolChoiceShadow.mjs` 及 API/Worker 接线；不启用建议或目录裁剪。

1. **旁路观察**：canonical Turn 的 Tool Loop 完成后异步触发；不改变主模型上下文、工具目录或执行选择。首期计划全局稳定抽样 10%，每工厂并发最多 2 批，全环境 Redis 共享最多 120 次分类请求/分钟。仅记录成功进入 Tool Loop 结束路径的样本，不覆盖 legacy Chat/Planner、Subagent 或所有失败 Turn，也不声称全量采集。
2. **再建议模式**：新题质量门槛及主模型配对验证通过后，仅影响建议/排序，保留完整授权目录。缺结果、超时或协议异常时跳过建议，继续原主模型路径；Turn 已取消则保持取消，不能以回退为由继续执行。
3. **默认关闭，部署时显式开启**：`AGENT_TOOL_CHOICE_SHADOW` 沿用全局/project/user rollout 语法；本次用户授权上线旁路后可显式开启全局抽样，配置模板仍为 false。`AGENT_TOOL_CHOICE_SHADOW_SAMPLE_PERCENT=10`、`AGENT_TOOL_CHOICE_SHADOW_REQUESTS_PER_MINUTE=120`。关闭停止新批次，不撤销已派发请求。
4. **记录停止条件**：发现只读请求引出危险调用、缺失授权能力、未知副作用重放或越权数据外传立即停止扩大流量；超时、错误、额外成本和端到端延迟超出事先确认的限值也退回原路径。具体限值在真实工具基准后确定，不沿用离线 8 次串行耗时作线上 SLA。
5. **版本发布/回退**：遵循 [在途 Turn 发布手册](../AGENT_TURN_RELEASE_RUNBOOK.md)。冻结哈希变化时旧版本排空后切换；不能批量取消、改 checkpoint 或删数据来制造排空。开关只停止新分类，不能让正在恢复的 Turn 丢失已冻结决策；代码回滚同样需排空目标版本。

上线记录必须分别列出 Git revision、API/Worker/前端部署版本、迁移状态、在途门禁、功能开关与灰度范围；本地门禁通过不能替代生产数据库清点、恢复 smoke 和回退演练。

回执保存模型/版本、输入和目录哈希、已派发/有效响应数、耗时、提供方报告的输入 token、主模型已选工具和分类预测；正文和参数不保存。`actualCost: null` 表示未知真实费用，不能按零元报告。`disagreementCount` 只是与主模型工具集合的差异，不是准确率。日志事件为 `botanic.agent.tool_choice.shadow`，无正文。进程崩溃可能漏采；已 claim 未完成的回执不自动补跑，避免重复费用。部分批次只可统计覆盖与错误，不能当完整工具选择评分。
