# ADR 0002：Agent 状态采用独立实体并保留文档兼容层

Agent Session、Message、Memory 与 Run 不再只作为 `CanvasDocument` 的整段数组保存，而是按项目和实体 ID 独立持久化。实体 ID 全局唯一，`project_id` 负责授权与归属；同一 ID 若出现在不同项目，写入或历史回填必须明确失败，而不是静默覆盖或丢弃。迁移期继续双写旧文档字段，新实体优先读取、旧字段作为兼容回退；Message 采用独立追加，Memory 采用删除墓碑，避免跨设备保存旧快照时覆盖新消息或复活已删除记忆。待历史项目迁移和双设备验证完成后，再停止旧字段写入，但本阶段不删除旧数据。
