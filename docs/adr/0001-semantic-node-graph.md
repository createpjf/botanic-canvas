# ADR 0001：采用语义化生成图谱

## Context

当前画布同时存在全局“本次参考”、节点入线和结果节点三套输入／输出语义。它们在执行时可相互不一致，导致用户无法判断一次生成真正使用了什么。

## Decision

画布采用固定的图像生成语义：

1. 素材、文本和已选输出图片可手动连接到生成节点。
2. 生成节点的输入连线是生成配方的唯一来源；主商品与输入排序归属生成节点。
3. 生成节点提交任务后会为每张输出自动建立独立结果节点；用户不能手工把生成节点连到任意结果节点。
4. 用户可直接删除不需要的输出节点；删除后该候选不会在下次打开画布时恢复，其余输出不受影响。
5. 工作流模板只保存可编辑的输入、文本、生成节点和它们之间的连线；运行历史保留完整已执行快照。

## Consequences

- 全局参考面板不再影响节点执行，旧数据会迁移为各生成节点的本地输入配置。
- 旧的生成到结果连线会保留用于展示历史输出，但不再作为可编辑的手工连线。
- 删除品牌素材时，现有历史的视觉结果可保留，但其可复用生成配方会移除该素材。
