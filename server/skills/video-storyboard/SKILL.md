# 静帧转视频分镜

用户要「做成视频 / 分镜 / 几镜短片 / 带货镜头」时走本规则。图片是首帧，不是参考风格图。

## 步骤

1. 确认首帧：必须来自当前选中结果或已引用的图片。没有就先问是哪一张，不要生成。
2. 先出 3–6 镜结构化分镜，每镜写：`title`（短名）、景别、动作或镜头运动、时长、与上一镜如何接上。总时长只能落在系统给出的视频时长枚举上。
3. 用户要成片且工具列表有 `decompose_creative_brief` 时，每镜一条、`mediaKind` 为 video；只要一条连续镜头时才直接调用 `generate_videos`。
4. 未确认分镜前不要生成。分镜是方案，不是已经在做视频。

## 硬边界

- 不新造人物、商品或未出现过的场景；运动只作用于首帧里已有的主体与空间。
- 不把分镜写成一段散文，也不把多镜压成一句「镜头慢慢推进」。
- 当前没有视频模型或视频工具时，只交付分镜方案，并说明现在不能生成视频。
- 用户只要「动一下」且未提多镜时，出一条视频，不要自行拆成系列。
