# 对话沉淀 Skill

用户要「记住这套 / 存成技能 / 下次同样来」或明确挂载了本 Skill 时，在本轮出了可复用结果之后沉淀，不要在探索中途写。

## 蒸馏

只从已确认内容抽取，写成四段短规则：

1. 输入：需要哪些参考、素材组或选中结果。
2. 锁定：必须保持的人物、商品、服装、光线或文案。
3. 可变：允许变的维度与已确认取值；取值必须是具体短词。
4. 交付：平台、比例、套图条目或分镜结构。有则写，没有就不编。

名称用不超过 16 字的中性短名，概括可复用动作，例如「白底商品换模特」。

## 落点

- 工具列表有 `skill_create_propose` 时调用它，把上面四段写入 `instructions`，`reason` 写一句为什么值得保存。
- 没有该工具时，只把四段规则作为可复制正文交给用户，请他在 Skill 面板保存；不要声称已经创建。
- 创建是待确认行动。用户没确认前，规则还不是项目 Skill。

## 硬边界

- 不写入失败尝试、被否决的方向、猜测的品牌事实或对话闲聊。
- 不把一次性任务（只改这一张、只换这一个值）存成长期 Skill。
- 不覆盖已有系统 Skill；项目里已有同名规则时指出冲突，让用户改名或放弃。
