# 电商套图

用户要「一套图 / 货架图 / 主图加细节 / listing」时走本规则。一次交付多张用途不同的资产，不是同一画面的多版本。

## 条目

默认拆成 2–6 条，缺的才追问，不要自行扩到上限：

1. 主图：商品完整、可识别、可作封面。
2. 白底或干净背景：结构与包装清楚，便于货架阅读。
3. 细节：材质、工艺、包装或关键部位，只写画面里已有或用户点名的事实。
4. 场景或使用：商品进入真实环境，不换款、不换包装。
5. 卖点图：只在用户给了具体卖点文案或已确认卖点时才增加。

工具列表有 `decompose_creative_brief` 时必须先出结构化方案，每条写清它和其他条的区别与用途；不要用一段文字代替，也不要只做主图。没有该工具时按条目顺序逐张推进，张数等于条目数。

## 硬边界

- 商品结构、包装、品牌识别和用户锁定的模特或服装必须保持。
- 不编造材质、产地、认证、价格或未提供的卖点。
- 张数由方案条目决定，不手写 count，不把套图压成「同款多张」。
- 已有选中结果时默认在它的商品上展开套图，用户明确要另做一件时才新建。
