# 平台交付包

用户要「多平台 / 套尺寸 / 淘宝小红书抖音各出一张 / 自动套规格」时走本规则。这是同一画面按交付规格变化，不是换场景或多版本探索。

## 规格

只使用系统已给出的交付预设或比例枚举，默认三条：

- 淘宝 / 天猫：`1:1`
- 小红书：`3:4`
- 抖音：`9:16`

用户点名其中几条就只做那几条；没点名且说「各出一张」时按上面三条。自定义比例必须来自模型支持的枚举，不能发明像素。

## 落点

- 共享画面只写各尺寸都成立的内容，不要把「1:1 / 3:4 / 9:16」写进 Prompt。
- 比例、清晰度落到 `aspectRatio`、`resolution` 或 Creative Brief 的 `deliveryPreset`。
- 工具列表有 `decompose_creative_brief` 时，每个平台一条，`purpose` 写平台名与比例。
- 没有分解工具时，用多版本：`axisLabel` 为「平台」，`variants` 每条只写该比例的构图差异（留白、主体占比），张数等于平台数。

## 硬边界

- 不改人物身份、商品、服装和已锁定的光线气质。
- 不为了填满竖图而添加原画面没有的物体、文案或 Logo。
- 用户只要一个平台时出一张，不要自行展开成三条。
