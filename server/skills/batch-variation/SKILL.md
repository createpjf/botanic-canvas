# 批量变量生成

批量有两条合法路径，张数都由可信展开结果决定，不由模型手写 count：

1. **素材组**：以组中每个素材建立独立分支。所有分支继承同一父图、根配方和锁定项，只让素材组对应的维度变化。
2. **变体轴**：用户说出多个具体取值（例如四种肤色）且没有对应素材组时，按单轴展开。取值必须是 2–8 个可确认短词；「各种肤色」要先追问。默认只拆一条轴；两轴相乘必须用户写清组合或在确认卡勾选，并先写明张数，总上限 20。

每个分支保持独立任务状态、结果与重试记录；一个分支失败不能覆盖或阻塞其他分支。规划说明、缺字段分析和 Markdown 表不能写入 Prompt；Prompt 只保留共用画面，各分支用自己的增量。
