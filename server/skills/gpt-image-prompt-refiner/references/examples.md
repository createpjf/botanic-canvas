# 提示优化案例

以下展示输入与目标输出风格。标注已提供的图片仅为案例前提，本包不包含这些图片，也不声称运行过生成。使用时以真实附件和当前请求为准，不把示例产品属性套到客户产品上。

## 1. 新图：抽象风格落实为画面

用户：“原创银色保温杯，做电商主图，有高级感，浅灰底，不要文字。”

```text
为一款原创银色保温杯创作电商主图。画面中只有一只完整保温杯，居中展示，四周保留适当空间，浅灰色干净背景。杯身呈细腻的金属质感，使用柔和的大面积侧光形成平顺反射，让轮廓与表面清楚可读；底部有自然接触阴影。构图克制，产品是唯一视觉重点。不要添加文字、商标、道具或装饰图案，不裁切杯身或杯盖。
```

没有添加品牌、容量、保温时长、获奖或价格。若是真实商品，应使用真实参考而不是套用这个原创设定。

## 2. 局部编辑：不把整个房间重新设计

用户：“优化这个编辑提示：把图 1 里餐桌旁的白色椅子换成木椅，别的别动。”

```text
仅将图 1 中餐桌旁的白色椅子替换为木制椅子，保持原有椅子的数量、位置、朝向和合理尺度。保留相机角度、房间布局、餐桌、周围物品与原有光线；新椅子具有自然木纹和与现场一致的接触阴影。不要改变其它家具或添加物品。
```

普通“别的别动”用清晰保留项即可；用户未要求像素证明时不附冗长技术说明。

## 3. 多参考：身份和风格分工

用户：“已附两张图。图 1 是我们的红色耳机，图 2 是喜欢的摄影氛围。只参考图 2 的光，给耳机出广告图，不要字。”

```text
以图 1 的红色耳机为唯一产品主体，制作无文字广告图。完整保留耳机轮廓、结构、部件数量、红色配色和现有产品标记。图 2 仅作为光线方向、柔硬和色调氛围参考，不采用其中的主体、场景物件或文字。耳机清晰突出，所有重要结构可辨认，反射与阴影自然一致。不要添加广告文案、新标志或额外物品，不重设计产品。
```

若未查看图 2，不臆造“紫色霓虹”之类细节；图号与角色足以清楚表达的部分可以直接保留。

## 4. 精确文字：保留中文而非自动英文化

用户：“做咖啡店海报，必须只有‘今日慢一点’这五个字，只出现一次。米白和深棕，留白多，不要英文。”

```text
创作一张咖啡店海报，以米白为主色、深棕为文字和视觉重点，保留充足留白，整体安静简洁。画面仅呈现以下文字，逐字准确且只出现一次：
“今日慢一点”
让这五个字成为清晰的视觉中心，使用易读、字距舒适的中文字体，文字与背景有明确对比。不要添加英文、品牌名、日期、标语或其它文字。
```

用户没有要求杯子、咖啡豆或具体品牌，不能为了“完整”强行添加。

## 5. 透明素材：提示和设置分离

用户：“把图 1 的洗发水抠成真正透明 PNG，瓶子和标签不变，给我提示和 API 设置。”

提示：

```text
从图 1 提取洗发水瓶，完整保留瓶身、瓶盖、形状、比例、颜色和标签文字，隔离在完全透明的背景上。主体完整居中，轮廓清晰，边缘没有光晕或杂边，保持原有产品质感。只移除背景和背景上的投影，不重设计或美化标签。不要添加实色背景、绘制棋盘格、文字、道具或新的阴影。
```

请求设置：目标模型与接口须支持图像编辑；设置 `background="transparent"`、`output_format="png"`，不传 `output_compression`；尺寸按用户交付要求及接口支持确定。

必要执行说明：实际输出须检查 Alpha 与标签；提示本身不能保证文件透明或标签完全未变。

## 6. 人物保持与换装

用户：“图 1 是人物，图 2 是衣服。只换成图 2 那件外套，脸、姿势和背景保持。”

```text
仅将图 1 人物的外套替换为图 2 中的外套。图 1 决定人物身份、面部特征、发型、身材、姿态、构图和背景，全部保持不变；图 2 只提供外套的款式、颜色、材质和细节，不迁移图 2 中的人物或背景。让外套自然贴合图 1 的身体姿态，褶皱、遮挡和光影与原场景一致。不要改变其它服饰或配饰。
```

## 7. 风格迁移：保留用户指定的非写实目标

用户：“这张城市照片改成粗糙的黑白木刻，不要变精致，楼和街道位置不变。”

```text
将输入城市照片转为粗糙、有手工痕迹的黑白木刻图像。保留原图建筑轮廓、街道位置、空间布局和构图。用大块黑白对比、明显刻痕和不完全均匀的线条表现明暗，允许粗粝边缘与刻刀肌理。不要加入颜色、写实材质、平滑渐变或精致抛光效果，不增减建筑或改变道路走向。
```

不能因为“优化”而把粗糙目标改成高端商业摄影。

## 8. 科学示意图：明确关系，不补造事实

用户：“给初中生画水循环，节点只有蒸发、凝结、降水、汇流，箭头按这顺序闭环，简洁中文。”

```text
为初中生创作一张简洁的水循环示意图，使用清楚的中文标签和易辨认的自然场景图标。四个节点仅为“蒸发”“凝结”“降水”“汇流”，按“蒸发 → 凝结 → 降水 → 汇流 → 蒸发”的顺序用单向箭头连接成闭环。文字各出现一次，字体清晰，箭头方向明确，节点间保留充足空间。采用浅色背景与统一的扁平图形风格，不添加其它过程节点、数据或装饰性文字。
```

如果用户给出的关系明显不成立，应先说明并澄清；不能为了忠实改写而把已知错误包装成科学事实。

## 9. 系列图：只有用户要求才给多条

用户：“同一个原创角色两张图，一张看书，一张撑伞。两张独立图，给两条完整提示。已附角色图。”

提示 1：

```text
使用输入角色参考图中的同一原创角色，保持其面部特征、发型、身体比例、服装、配色和原有插画风格。创作一张角色安静看书的独立插画：角色自然坐着，双手持书，视线落在打开的书页上，书和动作清楚可见。背景简洁，让阅读动作成为重点。不重设计角色，不添加文字，不制作拼图。
```

提示 2：

```text
使用输入角色参考图中的同一原创角色，保持其面部特征、发型、身体比例、服装、配色和原有插画风格。创作一张角色撑伞的独立插画：角色自然站立，一只手握住伞柄，雨伞在头顶形成合理遮挡，人物和雨伞完整可见。背景简洁，让撑伞动作成为重点。不重设计角色，不添加文字，不制作拼图。
```

## 10. 必须说明的限制

用户：“只换天空，建筑和地面的每个像素必须原样，给提示。”

```text
仅将输入图中天空区域替换为晴朗的蓝天与轻薄白云，保持原天空与建筑交界的位置，不改变建筑轮廓。建筑、地面、人物和其它非天空区域不做重绘或调色，不添加物体。
```

必要执行说明：逐像素保持需要将天空编辑合成回原图，并验证非天空区域像素一致；不能仅靠生成提示保证。

用户：“只有产品正面照，做忠实的背面图，不许推测。”

此时先索取同型号背面资料或可靠结构来源；不生成“根据正面准确恢复背面”的虚假保证提示。可先优化不依赖背面的正面任务。
